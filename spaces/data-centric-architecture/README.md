# Data Centric Architecture

A place for information and discussion about the Data Centric Architecture. I am thinking this is more about the concept than about our implementation. However, if our implementation is a **Reference Implentation** them maybe descriptions about it fit here as well.

![](attachments/676823279/677216266.png)

Layers of the DCA:

1. Data store  
   1. Curated Data
   2. Mapped External Data
   3. Harvested, aligned data
   4. Provenance data
2. Federated Query layer over data storage
3. Core Ontology (JG: probably should be called the Architecture Ontology)

   1. Meta Data => Ontologies, SHACL
4. Data Security & Access logging
5. Data Identity Management
6. Integrity Management, Constraints and Triggers

   1. consistent, correct data
   2. data compliance
7. Programmatic Behaviors
   1. Geospatial, Temporal, Mathematical, Workflow
8. Domain Ontologies & Taxonomies
   1. JG: Often includes a "Core" ontology/taxonomy for the organization
   2. JG: and "Domain" ontologies/taxonomy for different parts of organization
9. Endpoint Access Management
10. User Interfaces (applications)
    1. Hard coded? Model Builders
    2. Model driven UI
    3. Bespoke UI
