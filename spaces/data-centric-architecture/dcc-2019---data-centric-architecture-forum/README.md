## Summary of 2019

Dave's summary:

- Creating a data-centric architecture is an essential pursuit.
- There is nothing that anyone in the group (and this is a group with a lot of coverage) knows of that does what a DCA has to do, out of the box.
- We think we have identified the key components.  Some of them are difficult and have many design options that are still open, but no aspect of this is beyond the reach of competent developers, and none of the components are even that big or difficult.
- The strawman held up pretty well.  It seemed to work pretty well as a communication device.  We have a few proposed changes.
- We all learned a great deal in the process.
- I think one thing we all agreed was that it wasn’t a conference, or at least not a conference in the usual sense.  I think going forward we will call it the data-centric architecture forum.  Seems more fitting.

## Lessons Learned from 2019

- Need to bring in some experts for the security discussion for 2020.
- Need to set up a Google Doc environment for sharing notes and presentations.
- Attendees appreciated the Estes Park contextual info in advance.
- Vendors need to be better integrated in the physical space and schedule.
  - Attendees requested opportunity for demos.
