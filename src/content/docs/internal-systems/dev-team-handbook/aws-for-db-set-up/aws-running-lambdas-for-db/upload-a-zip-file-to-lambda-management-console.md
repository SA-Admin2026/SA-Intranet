# Upload a Zip File to Lambda Management Console

On the configuration tab, of the lambda management console, about halfway down, is the code entry type, which defaults to edit code in line.  Change it to upload a zip and an upload button will appear

![](/internal-systems/attachments/240910410/240779306.png)

Don't forget to hit the now orange Save button.
