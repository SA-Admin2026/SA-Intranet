## GraphDB License Updates

Our GraphDB licenses expire every 6 months or so (usually in July & January). They have been pretty good about emailing us new licenses ahead of time (from [ivan.antrov@ontotext.com](mailto:ivan.antrov@ontotext.com)

). The license file usually has a name like `PARTNER_H1_GRAPHDB_ENTERPRISE_expires-10-07-2024.license`. You can update the license from the GraphDB user interface if you login as the `admin` user.
