This page is a place to collect ideas for what we should do for a next major release.

1. be consistent in all property naming.
   1. use tense-neutral verbs for all object properties
   2. open question what do use for data properties. Dave likes nouns. I don't mind too much that convention, but it is non-standard, and given a triple is just as much a assertion with a subject predicate and object as an object proerty triple, I lean towards having them also sound like verbs. It means you can read the triple like a sentence and disambiguates the order.
2. definitions
   1. use skos:definition
   2. have a consistent pattern for all definitions,
   3. use other annotation for other comments, possibly just rdfs:comment
