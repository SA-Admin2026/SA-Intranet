# Choosing a Location for the DBBO Class

## Marketing Considerations

- Identify three target companies
- Look at local Meet Up groups
- Look at local universities (e.g., computer science, Info science, library science programs)
- Pipedrive contacts

## Timing Considerations

- Check to see if the date corresponds with other events.
  - Good events
    - Piggybacking on other conference offerings
  - Bad events
    - Holidays that could negatively affect travel plans (e.g., Easter, Spring Break)
    - Highly attended sporting events that drive up airline and hotel costs (e.g., PGA Master's Tour)

## Geographical Site Location

- City has more than three target companies
- City is good travel hub for airlines (and hopefully train)
- City has more than three Meet Up groups that are closely aligned with our mission (e.g., ontologies, taxonomies, graph data, Internet of Things, artificial intelligence etc.)
- City has at least one university with activity in ontologies

## Hotel Amenities

- Conference room
- Conference room rate should range from 1 night before class begins to 1 night after course ends
- Catering needs
  - Morning coffee / breakfast
  - Morning snack service
  - Afternoon snack service

# Before Class Begins

## Logistics

1. Divide up the course content and identify which instructor is covering which content.
2. Identify who needs to do what while on-site (e.g., taking notes/errata, set up, take down, etc.)
3. Set aside time to set up equipment and test it.
4. Set expectations on how you want to run course.
   1. Co-teaching topics v. each person responsible for individual sections
   2. Taking notes
      1. Individual v. group effort
      2. How to compile notes and who is going to do it
      3. Written v. electronic
   3. Divvying up social activities (We are all introverts and four 14-hour days of "on time" are exhausting. Might want to plan so each instructor gets at least one morning or evening of solitude and re-charge time.)
      1. Morning set up and chatting with students
      2. Group / social lunches - maybe rotate, so each instructor hosts a group lunch with the students, giving the other instructor(s) re-charge time?
      3. Group / social dinners - maybe rotate, so each instructor hosts a group dinner with the students, giving the other instructor(s) re-charge time?
      4. Happy hour
      5. Possible offering of an open house to the general public on day 1?
         1. We could invite Meet Up groups to attend.

## Update PowerPoint Slides

1. Make any remaining changes from errata from last time.
   1. Ideally, this task was completed at the end of the previous course.
2. Make any other improvements.
3. Update the slides with the trainers' photos and mini-biographies.
   1. beginning of opening lecture
   2. end of closing lecture
4. Update the lecture header pages to contain the new date and place.

## Prepare DBBO Course Materials for Printing

1. Update booklet cover page with right dates and place.
2. Change master file footer to be right place and date.
3. Make sure slides are completely updated, no more tweaking.
4. Update the PowerPoint files on the GitHub site.
5. Assemble all the PowerPoint files into one master.
   1. Print two slides per page via the Handout menu.
6. Save as a pdf called something like All-2017-Mar-FC.pdf.  **(See note below)**

## Prepare Other Handouts:

For each student and instructor, print the following:

1. Protégé instructions document
2. Instructions for text editor (some students do not have this already installed)
3. Agenda
4. Additional Resources Handout - to point students to helpful info after class.  (TBD)
   1. Suggestions: Bob du Charme's SPARQL book, Schema.org; geoNames.org; FIBO; FOAF; Protege google / support group; W3C standards; open source tools (e.g., Stardog free version; TopBraid free version, etc. [ANSI/NISO Z39 for taxonomy standards](https://groups.niso.org/apps/group_public/download.php/12591/z39-19-2005r2010.pdf))
5. Local information
6. Post-course survey
7. Suggest a TARQL handout on how to convert tabular data to RDF

## Send to FedEx in the Destination City

1. Count of how many booklets are needed.
   1. one for each participant
   2. one for the trainers, and
   3. sometimes a spare if numbers are uncertain (mostly only applies for in-house training).
2. Call FedEx a week in advance to see how long it takes to print the number of books you need.
3. Send FedEx instructions, The booklet consists of:
   1. Clear plastic front
   2. Printed on 20-pound white paper
   3. Cover page (blank on back)
   4. Agenda
   5. PowerPoint files
   6. sturdy-ish black plastic back
   7. Spiral bound
4. It is best to have a quick look at a pdf proof before printing, they sometimes make mistakes. This is especially true if you do anything complicated, like insert different colors in between each lecture, or have each new lecture start on a right-hand page.

1. Make a copy of all the slides that went into the booklet.

   1. Cover any irregularities of your own idiosyncratic set up.
3. ~~Put the PowerPoint files in Dropbox so either trainer can edit them while the other is speaking.~~

## Notes and Errata

Ways to take notes include the following:

1. directly in the slide deck so no transfer of notes to slides needs to happen  
   (NB: be careful to avoid clashes, if using files in dropbox)
   1. New comments in slide notes section
   2. Quick fixes to the slides themselves, typos etc
2. a word file
3. Illegible scribble on the paper copy of the manual.

## Last day:

1. Give feedback forms to students.
2. Mail projector and box of equipment back to Semantic Arts home office.
3. If so inclined, take a class photo.
