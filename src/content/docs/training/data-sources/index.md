We may need data to populate databases or semantic stores for various projects, proposal, or examples. This section documents known sources of data.

## General Data Sets

- <https://data.world/>
- Google Dataset Search
  - <https://toolbox.google.com/datasetsearch>
  - Blog post about Google Dataset Search (beta) <https://www.blog.google/products/search/making-it-easier-discover-datasets/>
- GitHub
  - <https://github.com/awesomedata/awesome-public-datasets>

## Government Data Sets

- US Federal, State, and Local Government Agencies
  - <https://www.data.gov/>
- US Census Bureau 
  - <http://www.census.gov/data.html>
- European Union Open Data Portal 
  - <http://open-data.europa.eu/en/data/>
- United Kingdom
  - [Data.gov.uk](http://Data.gov.uk) <http://data.gov.uk/>

## Finance Data Sets

- Google Finance
  - <https://www.google.com/finance>

## Corporate Data Sets

- Amazon
  - <http://aws.amazon.com/datasets>

## Data Sets with Document Metadata

(May be useful for libraries, Smithsonian, cultural institutions)

- British National Bibliography
  - [Data.gov.uk](http://Data.gov.uk) <http://data.gov.uk/>

## Geospatial Data

- <https://www.geonames.org/>
