From some emails w/ Dr. Sameer Joshi:

*Granular encryption is already implemented [*in their tool suite*].*

*You can encrypt by adding a few lines to Scheme (or via the GUI). The system automatically:*

*1.       Creates a Map Reduce job to encrypt the relevant data on disk.*

*2.       Encrypts new data coming in.*

*Encrypted data are queryable via SPARQL.  We have created a SPARQL engine extension where you can supply the key at query time for safe querying.*
