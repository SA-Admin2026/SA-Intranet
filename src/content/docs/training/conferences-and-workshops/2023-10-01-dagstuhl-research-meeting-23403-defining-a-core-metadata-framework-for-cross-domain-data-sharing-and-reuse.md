Defining a core metadata framework for cross-domain data sharing and reuse

[Research Meeting 23403](https://www.dagstuhl.de/en/seminars/seminar-calendar/seminar-details/23403) is one of a series of meetings organised by [CODATA](https://codata.org/) and the [DDI Alliance](https://ddialliance.org/)

The workshop was dealing with the core metadata requirements to improve access to data, mainly research data. Key issues dealt with at this specific workshop included

- access to research data (overcoming the current paper-based legal aspects of accessing research data for specific purposes),
- developing JSON-LD profiles of existing ontologies ([DCAT](https://www.w3.org/TR/vocab-dcat-3/), [ODRL](https://www.w3.org/TR/odrl-model/), [QB](https://www.w3.org/TR/vocab-data-cube/), [PROV-O,](https://www.w3.org/TR/prov-o/) etc) using the [Open Geospatial Consortium](https://www.ogc.org/) [bblocks toolchain](https://github.com/opengeospatial/bblocks) to facilitate automation of what is currently done manually in many settings that use semantic technologies for information integration
- standard expressions of universals - concepts that occur in many domains and currently are represented multiple times in various forms across a number of ontologies (e.g. UoM)
- how to describe events, occurrences and samples

The workshop also included a presentation on ‘gist’ and this is included in the workshop materials
