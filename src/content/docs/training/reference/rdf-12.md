RDF 1.2 (Resource Description Framework, version 1.2) is the W3C's latest revision of RDF. It is the successor to RDF 1.1 and incorporates work from RDF-star / RDF\*. RDF 1.2 adds reification using Triple Terms and`rdf:reifies`; directional language strings; and version announcement. As of April 2026, it is a W3C Candidate Recommendation.

- [![](https://semarts.atlassian.net/wiki/download/thumbnails/3327426562/RDF%201.2%20Reification.pdf?version=1&modificationDate=1779821625428&cacheVersion=1&api=v2&viewType=fileMacro)](/attachments/3327426562/3327721473.pdf) OKE Presentation

Discusses reification in RDF 1.2 (RDF-star / RDF\*), i.e. using `rdf:reifies` and Triple Terms (`<< s p o >>`) to attach provenance, confidence, temporal, and other metadata to facts, with asserting/non-asserting modes, Turtle, RDF-XML, and JSON-LD syntaxes, SPARQL queries, and a comparison to LPG edge properties.
