## What others are doing or have proposed:

- R43ples - [paper](https://pdfs.semanticscholar.org/187e/60acfcc687b21c2a8887626b1e28d19f03aa.pdf) - [github](https://github.com/plt-tud/r43ples)
- [TopBraid Change](https://topbraid.org/change) - An RDF model that can be used to represent changes to an RDF graph.
- [SEMVERSION: An RDF-based Ontology versioning system](http://citeseerx.ist.psu.edu/viewdoc/download?doi=10.1.1.217.84&rep=rep1&type=pdf)
- [Vocab.org Changeset](http://vocab.org/changeset/) - This vocabulary defines a set of terms for describing changes to resource descriptions.
- [Towards Versioning of Arbitrary RDF Data](http://ul.qucosa.de/api/qucosa%3A15777/attachment/ATT-0/) - [also](https://www.researchgate.net/publication/303924732_Towards_Versioning_of_Arbitrary_RDF_Data) -
- [Version Control and Change Validation for RDF Datasets](https://www.researchgate.net/publication/321030790_Version_Control_and_Change_Validation_for_RDF_Datasets/download) - Research Conference on Metadata and Semantics Research
- [Distributed Collaboration on RDF Datasets Using Git](https://svn.aksw.org/papers/2016/Semantics_Quit/public.pdf)
- Tim B.L comments on [RDF Diff, Patch, Update, & Sync](https://www.w3.org/DesignIssues/Diff)
- TerminusDB presentation on their [distributed graph version management](https://www.youtube.com/watch?v=dulKiZuI_NE)
