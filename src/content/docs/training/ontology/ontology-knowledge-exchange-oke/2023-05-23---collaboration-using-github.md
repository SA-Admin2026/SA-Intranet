- Best Practices for Code Collaboration

  - Begin by pulling the most recent develop and starting a fresh branch
  - Frequently pull into your own branch from develop
  - When tweaking a pull request,

    - make a branch off of it, or
    - create inline "suggestions" using GitHub "add a suggestion" feature (Jamie demoed)
