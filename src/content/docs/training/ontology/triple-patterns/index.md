Triple patterns are a convenient way to express the way an ontology is intended to be used.

Triple patterns can be used early in a project to organize thoughts about what needs to be in the ontology.

They can be used to:

- create diagrams for review with client to validate concepts
- create diagrams to validate that all necessary triple patterns have been identified
- define the way data from external sources can be transformed to load into the knowledge graph
- validate that the triples created conform to the intent of the ontology
- validate that the ontology has the intended semantics
