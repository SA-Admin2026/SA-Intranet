In a cybersecurity analysis scenario, as with all analysis scenarios, relevant data is needed in the graph. Most enterprises, ingest a mixture of relevant data and irrelevant data, the latter being noise.

Certainly, the enterprise will have security appliances, security software, and human security analysts that will be generating both signal and noise. The advantage of using a gistCyber graph analysis system is that the cyber domain expertise encapsulated in the ontology can recognize, correlate, and make sense of the data in the graph.
