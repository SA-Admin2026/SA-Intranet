Units of Measure and Aspects are reference data; they are static and re-usable. As we work with different clients, we can grow a set of curated reference data for Units of Measure and Aspects that can be used on future projects.

The reference data can be used to:

·      market our services

·      save time on projects

·      re-use data from project to project

Only a few of us will need to do the curation and understand the details, while most of us will only need to use a small set of canned queries below to view the data and find the data needed for a given project.

 SPARQL queries against the reference data allow us to:

·      identify Aspects used by a given Discipline

·      identify correct Units of Measure to use

·      validate that correct Units of Measure have been used

·      convert values from one Unit of Measure to another

·      construct new Units of Measure from exiting Units of Measure

·      validate Unit of Measure data

 Our copy of the reference data is in our namespace. Recommendation: when populating reference data in a client environment, use their namespace.

 The Unit of Measure reference data, seeded from QUDT, is available at:

[Unit of Measure Reference Data](https://agraph.semanticarts.com/#/catalogs/demo-catalog/repositories/UnitsOfMeasure)
