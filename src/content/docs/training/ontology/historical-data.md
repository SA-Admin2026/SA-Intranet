I put together a relatively simple way to capture and query historical data, just in case we find a need for it. The approach is perhaps “bare minimum” but once understood can be extended, especially if SPARQL ever allows CONSTRUCT to be used in subqueries (allowing the history filters to be placed in the outer query).

I’m expecting some client, somewhere, someday, will want this or something like it.
