This page is to provide experiences, options and advice on good ways to publish ontologies in HTML.

Factors to consider

- Open source or paid
- Ease of use
- Features and functionality

Examples include:

1. WIDOCO   
   See: [WIDOCO Tutorial (dgarijo.github.io)](https://dgarijo.github.io/Widoco/doc/tutorial/)
2. schema dot org  
   e.g. [Organization - Schema.org Type](https://schema.org/Organization)
3. Whatever is used by the W3C (seems very close to WIDOCO).  
   e.g. [PROV-O: The PROV Ontology (w3.org)](https://www.w3.org/TR/prov-o/)
4. What FIBO uses  
   e.g. [gas commodity @en (edmcouncil.org)](https://spec.edmcouncil.org/fibo/ontology/DER/DerivativesContracts/CommoditiesContracts/GasCommodity)  
   FIBO uses ontoviewer <https://github.com/edmcouncil/onto-viewer>

5. <https://rhizomik.net/redefer/rdf2html>
