All are self-contained and stuff stays within the browser.  No tracking, no server callbacks et

Turtle Editor

For all files that you want to bring in from a QSA, use ?dot=

apart from RDFa.  To extract use the QSA ?rdfa=

URLs can also be pasted into the input box and there’s a button to pull that into the editor

Ctrl+F in the editor brings up the ‘find’ box, and clicking the “+” sign within the box (lower LHS) brings up the ‘replace’ box

For RDF you can input turtle, ntriples, and RDF/XML and it *should* work OK

There is a button to open a file picker, and a ‘download’ one which downloads the current content of the editor pan

Graphviz

start with “digraph someName {  }” and just add things within the curly braces.  See<https://renenyffenegger.ch/notes/tools/Graphviz/examples/index> and other inspiration on the web
