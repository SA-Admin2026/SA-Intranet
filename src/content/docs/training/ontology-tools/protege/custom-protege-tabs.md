Protege is based on the Eclipse Editor, and as such allows much customization of the user interface.

I have customized the Entities tab. I find my version to be much more useful than the default one. My customization allows me to see Classes, Properties, and Individuals all in the same tab.

I have attached my tab as an XML file. To try it, do the following:

1. Download the attached `Entities.layout-mw2020.xml` file
2. In Protege, use **Window > Import tab…**  to import the downloaded file
3. Give it a name, e.g., **Entities** or **Entities MW**

A snapshot of the tab is shown below.

![](/attachments/1148878857/1147306024.png)

Note how

1. Classes, object properties, data properties, and Individuals can all be seen in 1 view
2. Right-hand side is dynamic, based on what you select on the left-hand side.
3. You can see inferred versions of Classes, object properties, data properties using the Asserted/Inferred pull-down menus in each view.
4. You can see annotation properties in the center section by selecting that tab.
5. You can see all Individuals (with no type info), or Individuals by asserted type, or Individuals by inferred type, by selecting the corresponding tab in the center section.
6. You can see concept usage vs. annotations by using the tab in the top right-hand section.
