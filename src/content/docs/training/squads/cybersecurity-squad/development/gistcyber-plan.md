# Sounds Like a Plan

It would be useful to have a Plan model for cybersecurity such as the P-Plan. The scope of a Plan is broader than cybersecurity but since it is not currently in gist we’ll have to develop it in gistCyber and propose that it be promoted to gist.

# Purpose of gist:Plan

The gist:Plan should provide a structure for workflows. Planning a workflow, executing a workflow, and recording the results of the workflow are the essential parts.

## The P-Plan is an inspirational model for the gist:Plan.

The [P-Plan ontology](https://www.opmw.org/model/p-plan/) is a mature model that is worth considering for gistCyber. Should we be using P-Plan for inspiration, or should we actually import P-Plan? I think the question should be debated.
