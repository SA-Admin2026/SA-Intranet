A new folder structure has been created on the shared drive at “\_SemanticArts\Offerings\Data-centric Methodology”. This is a place to store slide decks and documents or shortcuts to documents. The intention is that these will provide an organised set of curated assets that will describe our methodology.

Link: [Methodology](https://datacentric.sharepoint.com/:f:/s/staff/El0_DaHmce9JlVq2LIID_rcBpMO5eqtxCkGFAdh3k1XeAQ?e=vuxkHM)

The methodology will be organised across several headings, and within each of the terminal headings are 3 folders:

- Guidelines
- Examples and Exemplars
- Checklist

The file structure is as follows:

|  |  |
| --- | --- |
| **ThinkBig**   - Inventory of Information Sources - Business Model - Parti - Initial List of Concepts - Postulates and Hypotheses - Modularity Plan - Distinctionary - Slow Reveal - OWL EO | **StartSmall**   - Specific Data Sources - Competency Questions - Domain Parti - Distinctionary domain - Slow Reveal - Instance diagrams - OWL - SHACL - Data load - SPARQL |
| **SemOps** | **Advisory Services** |

**Next Steps:**

To populate the repo please add your materials to the relevant directory. If material seems to fit in more than one category then, ideally, split it into category-specific presentations or documentation. If this is not possible then place one copy in a folder and link to it from other folders using an appropriately-named shortcut.

Please use a naming convention that starts off with the year, then mentions the client and the specifics of the document. e.g. “2020\_Morgan\_IntRisk\_CQ.ppt”. Try to be consistent with the naming of clients and the use of abbreviations

**Tools**

In the top level folder is a powershell script to create a spreadsheet of all items in the folder hierarchy. We can use this to help in managing the files as the population of this repository progresses
