## Encrypting Your Hard Drive

### PC

1. Go to Settings > Privacy & Security
2. Click “Device Encryption”
3. Toggle “On”

### Mac

([About encrypted storage on your new Mac - Apple Support](https://support.apple.com/en-us/HT208344))

Turn on FileVault ([Use FileVault to encrypt your Mac startup disk - Apple Support](https://support.apple.com/en-us/HT204837)) so that your Mac requires a password to decrypt your data

Instructions for macOS Ventura or later

1. Choose Apple menu > System Settings
2. Click Privacy & Security in the sidebar
3. Scroll down to the FileVault section on the right, then click “Turn On”

See the link above for earlier versions of macOS

## Backups

There are a few options here, which include:

1. Manual backups of important files to a thumb drive or external hard drive
2. Saving all files on a cloud based solution which automatically backs up (think OneDrive or DropBox)

Note: Semantic Arts work should be saved to the SharePoint library or other shared location whenever possible.

## Log-In Credentials

Your computer should require some type of authentication to access. This could be FaceID, fingerprint, password, pin, etc.

The settings should require authentication each time the computer is turned on, opened, or awakened from sleep.

## OS and Applications

You should regularly check for system and application updates, or set to update automatically where possible. Install required and optional updates to ensure protection.

## Enabling “Find My…” Services

### PC

1. Navigate to Settings > Privacy & Security > Find my device
2. Ensure the toggle is on
3. Click “see all your devices linked to your account”

   1. You should be able to see your computer and have an option to “Find my device”. Clicking this should open an option to locate it’s current position, and lock or unlock the device

### Mac

## Password Manager

Password managers, though not perfect, are a convenient and secure way to store login credentials. You should set a different password for your password manager than your other applications, and require 2 factor authentication to open.

You should also set a time out rule if possible to have the password manager prompt for password often. This will help if your computer should be breached to keep your passwords secure.
