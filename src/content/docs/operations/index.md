else's nav. See [`ACCESS.md`](https://github.com/SA-Admin2026/SA-Intranet/blob/main/ACCESS.md).

process docs that aren't firm-wide reference. It's stood up now, with placeholder content, so
we can prove the path→group gating end to end before real content lands.
