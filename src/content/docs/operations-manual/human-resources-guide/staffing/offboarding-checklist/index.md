# Semantic Arts Offboarding/Separation Procedures

### Employee Folder

* Move personnel file into past employee folder in Box, keep all relevant documents in accordance with data management policies
* Make a digital copy of employee’s digital assets and save to their employee file

+ This is a pain now. The best option is to access their email address via the outlook application (change the password to something you know). Once in the web application you can export their files and save it in their Employee Folder
+ Download the link to their onedrive and save any relevant docs in their Personnel folder as well

### Compliance & Reporting

* If the employee was in Colorado, you must send a Colorado Separation Notice (Copy found in HR Folder - Compliance).
* Send any relevant severance document, schedule the payment once the document is signed
* Offboard in Insurance portal Navigator and send relevant COBRA documents (US)
* If part of our Optum, need to access the portal to remove them from our group
* Offboard in Rippling. Don’t set up the pay run, do this independently

+ Voluntary separation final payment made at regular payroll
+ Involuntary is usually paid as immediate as possible

* Revoke AG Permissions via the “semarts” user - use the “Suspend” option
* Work with Jamie to revoke Spark permissions
* Revoke Confluence permissions
* Revoke Expensify permissions
* Revoke GitHub permissions
* Update Coaching Spreadsheet
* Update Staff Plan
* Get office keys back (if local)
* Remove from Website
* Remove from [Semantic Arts gist Team · semanticarts/gist Wiki (github.com)](https://github.com/semanticarts/gist/wiki/Semantic-Arts-gist-Team)
* Conduct an exit interview if the process was voluntary
* Handle any additional reporting if in UK or CAN

A while after separation, be sure to remove their user in MS and alias their name to formeremployees. This will clear extra licenses and reduce login points.
