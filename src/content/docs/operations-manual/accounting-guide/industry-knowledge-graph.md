# Sales Receipts

Whenever a purchase is made on the IKG website, it will be through Stripe. You should receive an email confirming the purchase, then take the following steps:

1. Open Stripe and locate the specific transaction. You will need these details later on
2. In the IKG QuickBooks:

   1. Navigate to "Create Sales Receipts"
   2. Enter the person's name under the Customer (quick add if not already in the system)
   3. Set the date to the day the payment was submitted in Stripe
   4. Class is IndustryKG
   5. Item is Fee
   6. For a Stripe Fee, create a second line, item is CurrencyorCardFee. Make negative to reduce the total to the correct amount
   7. Save & Close

Once the transaction has hit the bank, go back into QB and record the deposit, matching the date it hit the bank account

# Year-End Tasks
