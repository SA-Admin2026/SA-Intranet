Make sure you login to an account with required permissions. You must also be in “single user mode”

Once there, go to File - Utilities - Import - IIF Files

Start with the smaller ones like CAN or UK, do US last

Ensure each is run successfully

If the upload fails, it is most likely due to a new employee. The name from the IIF must match exactly what QB has. To make sure that is true, open the IIF with some type of viewer, then open QB “Add Employee” (ignore all the warnings you will inevitably get). Add the employee with an exact matching name. Then run the IIF again.
