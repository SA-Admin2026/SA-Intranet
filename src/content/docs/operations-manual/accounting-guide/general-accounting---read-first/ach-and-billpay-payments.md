We are attempting to move fully away from any type of payments where a provider can “pull” funds, and only allow those in which we “push” funds. This is to increase security around our banking information and ensure we are fully aware of our cash flow at all times.

When sending money out via ACH, the current procedure is that Dave will initiate the ACH payments via Key Bank and leave the remittance information on my desk. This will usually be in the form of a paper check printed from QuickBooks.

You then need to send a remittance to the receiver indicating that funds were transferred. In the [office@semanticarts.com](mailto:office@semanticarts.com) account, there is an email signature that has a good template for these emails, you’ll just need to fill in dates, amounts, invoice #s as appropriate.

In cases where we do not have the banking information required, Dave will set up a BillPay to send a paper check. These usually will not need a remittance advice but treat on a case-by-case basis.

As a last resort, the plan for any payments where a “pull” is necessary, Dave is going to set up an additional account that can be funded only with the amount we expect to be pulled. This will ensure the provider can’t pull extra funds above anticipated, and if the account falls into the wrong hands there are no funds to take. This could also be done the other way, where providers can send us money but it is immediately transferred out into a primary account for the same reasons.
