**Note: Reference the demo and word doc in the above folder for more information**

To share weekly:

1. Update the Onto Summary tab date to be about 4 or 5 weeks in the past
2. Glance through Proposed/Shadow projects to make sure the date is appropriate…ie not starting last week even though it isn’t signed yet

To add new projects:

1. Start in the Projects tab to add new projects
2. All start proposed or shadow
3. Need: Budget, write off, target start/end
4. Goal is for assigned to equal budget
5. Calendar shows which week number to use for the target dates

 After a project is entered, staff it:

* Staff tab has hourly rates and category
* Assignments

  + Project list is informed by projects tab
  + Total Days - # of hours divided by 8
